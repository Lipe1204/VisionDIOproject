# Visão computacional — experimentos do curso DIO

Registro de experimentos de análise de imagens realizados por Felipe Lemos Fonseca durante um curso. As pastas `inputs/` e `outputs/` organizam os materiais de entrada e os resultados publicados.

Este repositório documenta exercícios e observações de aprendizado. O serviço usado no curso realiza a análise; os modelos de visão não foram implementados pelo autor.
